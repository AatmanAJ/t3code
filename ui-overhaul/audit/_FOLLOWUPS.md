Method: code-read only (apps/web, apps/desktop, apps/mobile, apps/server read-only, packages/*). No app, Playwright, dev server or git write was used. Every item under "## Incomplete" and "## Needs deeper look" in `01-*.md` to `24-*.md` is classified:

- **a** RESOLVED BY CODE: answered from source with file:line. A trailing "(+live)" means a residual live check is still listed in the cell.
- **b** CONFIRMED-NEEDS-LIVE: not settled by code. The cell gives steps, fixture and the expected observation, written so Phase 2 can carry it as a verification task.
- **c** DUPLICATE or OWNED ELSEWHERE: the cell names the area and finding id.

Conventions:

- Pure housekeeping notes (process ids, simulators left booted, probe threads archived) are skipped. Host limits (no screen reader, no Windows) get one short b or c row.
- Paths are repo-relative. Line numbers are as read in this checkout (upstream `5f64c5eb` plus the interim audit commit). Some audit cites differ by up to about 20 lines (for example `threadTimeTimestamp` is `SidebarThreadRow.tsx:145-147`, the audit cited `:127-130`).

- Ground rules for every b row: use a throwaway server (own `--base-dir`, own ports) and disposable Playwright contexts; never redeem or revoke through the shared `state.json` session (area 11 incident); never kill by pattern, only a captured PID; synthetic data only.

## Key resolutions (read first)

1. **F-03-15 (Claude does not stream text): root cause found, server-only.** `ClaudeAdapterV2.ts:7650-7705` handles `message_start`, `message_delta` (usage) and thinking blocks, then returns; no `text_delta` is handled anywhere (`grep text_delta apps/server/src` finds nothing). Assistant text is emitted only from the completed SDK `assistant` message through `emitAssistantTextArtifacts` (`:6970-7009`) with `streaming: false` hard-coded (`:3343,3365`). Codex streams through `makeProviderTextDeltaCoalescer` at 50 ms with `streaming: !completed` (`CodexAdapterV2.ts:206,3244,3266,3362`). The UI is correct.
2. **F-21-13 / area 14 lead 1 (browser tab swallows chords): code confirms the mechanism, live decides the macOS outcome, and there is a second hazard.** `preview/Manager.ts:1462-1467` ignores every menu accelerator in a focused guest except copy, paste, cut, select-all, undo; only four chords are forwarded (`ReopenClosedViewShortcut.tsx:46-50,197-199`). The quit-hold handler is attached to the main window only (`DesktopWindow.ts:646`), so a single Cmd+Q with a tab focused either does nothing or quits at once, bypassing the default "hold" confirm (`settings.ts:230,371`).
3. **F-02-18 ("Waiting N"): the label is not "provider session idle".** It means background work holds completion (subagent or background task, or an awaited command or monitor: `orchestrationV2PendingBackgroundWork.ts:89-108`), or a thread with a provider thread and no run (`client-runtime/state/models.ts:226-227`). The counter counts from `latestRun.completedAt` (`SidebarThreadRow.tsx:1362-1367`, `status === "waiting"` branch).
4. **F-03-02 (scroll-up reverted): the proposed fix is already half there.** `handleWheel` already cancels live-follow synchronously (`useTimelineFollow.ts:318-331` to `:114-140`); the gap is the React state flush plus LegendList's smooth re-pin (`MessagesTimeline.tsx:1127-1141`, `TIMELINE_MAINTAIN_SCROLL_AT_END_SMOOTH` while working).
5. **F-01-04 root cause confirmed:** the readiness gate does not wait for repository-identity enrichment, which the server serves from a cache peek (`projectEntities.ts:118-129`, `orchestration-v2/http.ts:62-79`).
6. **Sidebar rename "double-click does nothing on non-active rows" has a code cause:** thread open refocuses the composer in a rAF (`ChatView.tsx:2069-2077`) and the rename input commits on blur (`SidebarThreadRow.tsx:818-822`).
7. **Keybinding "unbind" needs no contract change** (area 08 Needs 6): a custom rule with `when: "false"` suppresses the default (`server/src/keybindings.ts:493-502`, `web/src/keybindings.ts:72-73`).
8. **Corrections to DNA.md and DOCS-DIGEST.md are ready to paste** at the end (DNA 7.1 motion, DNA-S1/ID2 radius, DNA-C3 sidebar direction, DNA-V1a/V7a, nine DOCS-DIGEST rows, MAP.md rule count).
