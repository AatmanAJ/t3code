# 23 customisation-gap: audit

Area: what users can change today versus what a premium tool offers, evaluated against DNA. Code-read audit (no screenshots needed; every claim is `file:line` or a quoted prior-art number). Baseline `pingdotgg/t3code` main @ 5f64c5eb. Owner PR #24865 read from `prior-art/pr-24865.diff` and `pr-24865-body.md`.

Sources used, in the order the brief gave: `_PROTOCOL.md`, `_AREAS.md` section 23, `DOCS-DIGEST.md` "Customisation that already exists", `MAP.md` 5.3 persisted keys, `07-settings-appearance.md`, `packages/contracts/src/settings.ts`, `DNA.md`, `pr-24865-body.md`, `PRS.md`, `discussions.md` (plus `08`, `12`, `14`, `15` audits for overlap).

## Summary

- 27 candidates evaluated (the 17 in the brief plus 10 that users actually ask for in prior art): **11 exist, 5 are new and fit DNA, 11 are rejected.** 11 findings: 6 genuine gaps or bugs (F-23-02 to F-23-07), 4 discoverability, placement or stranded-setting fixes for things that already exist (F-23-08 to F-23-11), 1 correction of the digest (F-23-01).
- **Key insight:** the digest's "Customisation that already exists" table is wrong for 9 of its 30 rows. It says "no" for font family, sidebar width persistence, panel width persistence, diff view mode, diff word wrap and diff whitespace, and "partial/mobile only" for fonts, sizes and web/desktop notifications. All of these ship in `ClientSettingsSchema` (69 fields) and in Settings. The real gaps are not "more knobs": they are three persistence holes (sidebar collapsed state, right-panel width and terminal height for new threads, "Restore device defaults" blind to fonts), one prominent missing default (Thread details visibility, #15119, 15 up), and one accessibility override (reduce motion). Everything else users ask for is either already there or breaks DNA.
- Rule applied from the brief: anything in `docs/user`, on the Appearance page or in the settings schema is marked EXISTS and is never proposed as new; only discoverability or placement fixes are filed for it.

## Ground truth: what a user can change today

Persistence tiers (MAP 5.1/5.3, verified in `settings.ts`): device settings `ClientSettingsSchema` (69 fields, `settings.ts:309-479`, web `localStorage` `t3code:client-settings:v1`, desktop a main-process file) never leave the device and are never read by the native mobile app (mobile keeps `t3code.preferences`: `themeId`, `lightThemeId`, `darkThemeId`, `themeMode`, `baseFontSize`, `terminalFontSize`, `codeFontSize`, `codeWordBreak`, `persistence/mobile-preferences.ts`). Environment settings `ServerSettings` (about 62 fields) and per-project overrides follow the server. Layout state lives in separate keys: `chat_thread_sidebar_width`, `sidebar_state` cookie, `t3code:preview-panel-width:<threadKey>`, `t3code:right-panel-state:v2`, `t3code:terminal-state:v1`, `t3code:sidebar:{working,snoozed,settled}-expanded`.

Device settings by Settings page (row order as rendered, verified in `AppearanceSettingsPanel.tsx`, `TypographySettings.tsx`, `SettingsPanels.tsx`):

- **Appearance**: Themes (Color scheme tiles, six theme cards, Create theme, Add theme with Open VSX search) / Interface: 1 Contrast, 2 Glass opacity, 3 Environment identification (Dev and Nightly only), 4 Diff colors, 5 Composer context, 6 Chat width, 7 Render math (#24865 inserts "Colored project icons" between 6 and 7) / Motion: 1 Panel animations / Typography: 1 Interface font and size, 2 Monospace font and size, Advanced switch adds Prompt font, Terminal font, Font smoothing, then Word wrap.
- **General > Behavior**: 1 Thread notifications (4 modes), 2 In-app notifications, 3 Time format, 4 Response streaming (server), 5 Hide whitespace changes, 6 Default diff file state, 7 Diff layout, 8 Proactive panels, 9 Skills in slash menu, 10 Rich text composer, 11 Collapse composer on scroll, 12 Send shortcut, 13 Follow-up behavior, then provider-update rows. **General > Confirmations**: Unpin, Archive, Delete, Quit shortcut (desktop). **General > Organization**: Project grouping, Project order.
- **Beta**: Working section. **Keybindings**: full editor. **Project**: icon, emoji, monogram text, 18-hue icon colour (`ProjectIconPickerDialog.tsx:130-142`), stored on the project.
- Layout gestures: drag the sidebar edge, double-click to reset (`AppSidebarLayout.tsx:416`); drag the right panel edge (`RightPanelResizeHandle.tsx`, no reset); drag the terminal drawer top edge; collapse the Working, Snoozed and Settled shelves.

### F-23-01 The digest's "Customisation that already exists" table says "no" or "mobile only" for 9 things that ship

- Severity: P2
- Surface: all (internal docs; feeds spec section 7)
- Evidence: `DOCS-DIGEST.md:776-811` versus the schema. Digest "no": sidebar width persistence (`chat_thread_sidebar_width`, `threadSidebarWidth.ts:1`; reset by rail double-click, `AppSidebarLayout.tsx:416`), panel width persistence (`ChatView.tsx:3881`, `terminalUiStateStore.ts:177`), diff view default (`diffLayout`, `settings.ts:382`; `DiffPanel.tsx:885`), diff word wrap (`wordWrap`, `:474`), diff whitespace (`diffIgnoreWhitespace`, `:381`).
