Upstream pingdotgg/t3code `main` at 5f64c5eb. Read-only survey; nothing was run. All paths are relative to the

## 0. Ten-line orientation

- Stack: React 19 + React Compiler (`react({ compiler: true })`, `apps/web/vite.config.ts` plugins block), Vite+ (`vp`), TanStack Router
  (file routes, `tanstackRouter({ autoCodeSplitting: true })`), Tailwind v4 (`@tailwindcss/vite`, CSS-first config in `apps/web/src/index.css`),
  Base UI (`@base-ui/react`) primitives wrapped in `components/ui`, `class-variance-authority`, `tailwind-merge`.
- Server-backed state = Effect `Atom` (`effect/reactivity`) read in React through `@effect/atom-react` (`useAtomValue`). Local UI state = Zustand 5
  (`create` + `persist`), plus hand-rolled `useSyncExternalStore` stores (client settings, theme). Details in section 3.
- Timeline virtualisation = `@legendapp/list` (`LegendList`, `apps/web/src/components/chat/MessagesTimeline.tsx` L1110). Terminal = Ghostty WASM
  (`apps/web/src/terminal/ghostty/*`, `apps/web/scripts/build-libghostty-wasm.sh`), not xterm. Diffs/file trees = `@pierre/diffs`, `@pierre/trees`.
  Composer = Tiptap (`apps/web/src/components/ComposerPromptEditorTiptap.tsx`).
- Counts: web non-test source files 1162, unit/browser test files 347 (59 are `*.browser.test.*`). `components/` has 21 subdirs; `components/ui` 51 files.
- Three surfaces share `packages/client-runtime` (connection, state atoms, operations) and `packages/contracts`: web (+ desktop shell), mobile (Expo/RN + Uniwind).
- The app is "single origin" in dev: Vite proxies `/api`, `/ws`, `/oauth`, `/.well-known` (`apps/web/vite.config.ts` L263, `DEV_PROXIED_PATH_PREFIXES`). Never set `VITE_HTTP_URL`/`VITE_WS_URL`.
- A prior-run file `ui-overhaul/RUNLOG.md` exists (orchestrator log, not part of this map).

## 1. Routes (`apps/web/src/routes`, generated tree: `apps/web/src/routeTree.gen.ts`)

Router: `apps/web/src/router.ts` (`defaultPreload: "intent"`). History: `createHashHistory()` in Electron, `createBrowserHistory()` elsewhere
(`apps/web/src/main.tsx` L20-21). Bootstrap: `main.tsx` -> `AppRoot` (`apps/web/src/AppRoot.tsx` L15: `AppAtomRegistryProvider` > `RouterProvider`, plus
`ElectronBrowserHost`, `BrowserProfileReporter`, `QuitHoldOverlay` outside the router so webviews survive navigation). Optional Clerk shell is code-split
(`components/clerk/ElectronManagedAuthShell` or `BrowserManagedAuthShell`) and only loaded when `VITE_CLERK_PUBLISHABLE_KEY` and cloud config exist.

### 1.1 Layout nesting

```
__root.tsx  (beforeLoad resolves authGateState; RootRouteView L156)
 |- /guest                      bare Outlet (no providers, no session)
 |- /pair /connect /connect-agent   DocumentTitleSync + BrowserChromeThemeSync + Outlet (no sidebar, no ToastProvider)
 |- hosted prompt-link landing  (useHostedPromptLinkLanding) replaces the app
 |- /welcome                    ToastProvider > AnchoredToastProvider > theme/font syncs > CommandPalette > AppSidebarLayout > Outlet (no FirstRunGate)
 |- not authenticated           bare Outlet (the _chat guard redirects to /pair)
 '- authenticated | hosted-static: FULL SHELL (L232-278)
      ToastProvider > AnchoredToastProvider > {Sync components, coordinators} > FirstRunGate > CommandPalette > AppSidebarLayout > Outlet
      + ThemeEditorHost mounted above the router so drafts survive navigation (L273-274)
      '- _chat.tsx (layout, guard) -> ChatRouteLayout (L205): renders ThreadRouteView for thread/draft URLs, else <Outlet/>.
           Settings and Usage (isAppModalPage) render as AppRouteModal OVER the retained, inert ThreadRouteView (never remounts ChatView).
```

`authGateState.status` values: `authenticated`, `requires-auth`, `hosted-static` (app.t3.codes or `isLocalEnvironmentDisabled()`), `hosted-pairing`, `guest`
(`apps/web/src/routes/__root.tsx` L92-132; type in `apps/web/src/environments/primary/auth.ts` L130). Desktop with an unfinished SnapShot setup redirects
every path to `/settings/snap-shot` (`__root.tsx` L121-128).

### 3.3 Thread history paging and virtualisation

- Cold open is bounded: the thread snapshot comes from `fetchEnvironmentBoundedThreadSnapshot` (`packages/client-runtime/src/state/boundedThreadSnapshotHttp.ts`, 6 s timeout, query `compactTurnItems/dedupeBodies/compactIds`),
  falling back to the full HTTP snapshot for older servers (404 or invalid JSON) and then to the socket snapshot. Server-side window rule (`docs/internals/performance-regressions.md`): about 1 MiB of encoded rows, at most 10 user turns
  (20 on older pages) or 500 rows, otherwise 75 rows.
- `ThreadHistoryMeta` = `{historyCursor, hasMoreHistory, loading, error, expanded, latestLocalTurnOrdinal}` (`client-runtime/state/threadHistoryMerge.ts`). `loadEarlier` (`client-runtime/state/threads.ts` L650) fetches
  `fetchEnvironmentThreadHistoryPage` (`threadHistoryHttp.ts`, `cursor`, optional `throughEntryId`, `view=conversation|activity`) and merges older pages with `mergeOlderHistoryIntoProjection` without disturbing the live window.
  Once `expanded`, the thread is no longer persisted to the offline cache (`shouldPersistThread`, L112).
- `ThreadHistoryController` (`client-runtime/state/threadHistoryController.ts`) is a registry keyed by env+thread: each live thread registers a `{loadEarlier, reconcilePendingWork}` handler; UI/other code calls `loadEarlier(envId, threadId, throughEntryId?)` and gets `loaded|noop|busy|error`.
- UI: `ChatView.tsx` L523-542 builds `threadHistoryControls` (shown when `shouldShowLoadEarlierControl`), passed to `MessagesTimeline` (`historyControls`) which renders the "Load earlier turns" divider button (`TimelineHistoryControl`, `MessagesTimeline.tsx` L1179).
  Nothing auto-loads on scroll: paging is an explicit control (and `throughEntryId` for jump-to-message/citation).
- Virtualisation: `LegendList` (`MessagesTimeline.tsx` L1110-1160) with `estimatedItemSize={90}`, `maintainScrollAtEnd`, `maintainVisibleContentPosition`, per-type length buckets (L1215), `TimelineMinimap` overlay, follow/anchor/restore logic in `chat/useTimelineFollow.ts` (678 lines), `timelineScrollAnchoring.ts`, `useTimelinePositionRestore.ts`. Row model in `chat/MessagesTimeline.logic.ts` (2512 lines).
  There is also a `paintOnlyDisplayedTimeline` mode in `ChatView` that holds the previous thread's paint while the next loads.

### 3.4 Navigation memory

`components/sidebar/mainAppLocation.ts` keeps two module-level hrefs (`mainAppHref`, `appModalReturnHref`) so closing Settings/Usage returns to the page that opened them (`useCloseAppModal`, `useNavigateToMainApp`).
`panelAnimations.ts` `usePanelNavigationSuppression` suppresses panel transitions for two frames after any route change so switching threads does not replay panel animations.

## 13. Gotchas for UI changes

From AGENTS.md ("Taste", "Hit every surface"), `docs/internals/web-ui.md`, root `vite.config.ts` oxlint config and `oxlint-plugin-t3code`:

1. No-restyle: `components/ui` exports own their look; choose `variant`/`size`, do not override with `className`; only layout (width/flex/margin/position) goes on the parent. A one-feature look lives in that feature's own component; a generic look becomes a new variant. Enforced by `shadcn/no-restyle` (allow `layout`; `CollapsibleTrigger` is exempt). Do not style raw `<button>/<input>/<select>/<textarea>` into a control a primitive provides; do not import `buttonVariants` & co. (restricted import).
2. Compose, do not copy: follow the `ComposerBanner` slot-object pattern (slots own classes, take `className`, spread rest props, merge with `cn`; variants/density as props on `Root`).
3. Styles: Tailwind classes on the owning element. Global CSS in `index.css` only for generated Markdown/imperative DOM, custom elements/shadow roots, animations, runtime theme variables, browser/Electron integration. No `style={{}}`/inline `<style>` for static values (runtime-computed values are fine; existing precedents: slider progress vars, `--sidebar-width`). Theme-only rules use `@variant dark` / `@variant light`, never `.dark` selectors.
4. Lint on classes (apps/web/src outside `components/ui`): `shadcn/no-raw-colors` (use tokens; brand SVG files exempt), `shadcn/no-arbitrary-values` (short allow-list incl. `rounded-[inherit]`, `text-[0.86em]`, `bg-[Highlight]`; `auth/AuthSurfaceShell.tsx` exempt), `shadcn/no-unknown-classes`, `shadcn/require-static-classes` (no dynamically built class strings), `t3code/no-outset-state-indicators` (focus/selected/checked rings and outlines must stay inside the element: `ring-inset`, no positive outline offset),
   `t3code/require-centered-scroll-gutter` (`overflow-auto` scroller that centers content needs `scrollbar-gutter-both`), `t3code/no-unscoped-has` (`has-[...]` must be anchored to a class/attribute/id/tag), `t3code/no-native-title-tooltip` (use `Tooltip`), `t3code/no-raw-resize-observer` (use `lib/observeResize.ts`), `t3code/no-em-dash-copy` (no em dashes in strings or JSX text), `eslint/no-restricted-imports` (`@pierre/diffs/react` `CodeView` -> use `StyledDiffCodeView`; `@t3tools/client-runtime` needs a subpath).
5. React Compiler: every file under `apps/web/src` must compile (the compiler silently skips what it cannot prove). Lint errors: `react/hooks, refs, purity (warn), immutability, set-state-in-effect, set-state-in-render, static-components, exhaustive-effect-dependencies, memo-dependencies, preserve-manual-memoization, globals, unsupported-syntax`.
   No `useMemo`/`useCallback`/`"use memo"` (`t3code/no-manual-memo`); no `use*` function that calls no hook (`t3code/no-hookless-use-function`). Silent bailouts lint misses: `try/finally`, `throw` inside `try`; `reactCompilerCoverage.test.ts` is the backstop. Do not read refs or call `setState` in render/effects. Mobile still allows memo hooks (`allowMemoHooks`).
6. Large components (`ChatView`, `ChatComposer`, `Sidebar`): write handlers as plain functions, wrap with `useStableCallback` only where they leave the component (props, hook deps); module-level factories for functions children call during render or after `await` (V8 shared closure scope keeps old renders alive).
7. Animation: no continuously repainting animations; stepped keyframes, `observeVisibleAnimation` gating, `motion-safe:`; panel width/height transitions only through the panel-animation setting (default 0). Avoid per-frame layout work. Frame drops, "lying spinners" and stale labels are called out as the failure mode users notice.
8. Copy: no em dashes; `t3code/no-low-value-comments` caps comments (<= 4 lines, only for constraints/invariants); suppressions need a reason (`t3code/require-suppression-reason`).
9. Coupled constants: `--workspace-topbar-height: 52px` (`index.css` L121) = `MACOS_WORKSPACE_TOPBAR_HEIGHT` in `apps/desktop/src/window/DesktopWindow.ts` L41 (traffic-light position); `.wco` titlebar height 40; `apps/web/index.html` boot palettes must mirror `packages/shared/src/themePalettes.ts` (`themeBoot.test.ts`); `appearanceFonts.ts` default stacks mirror `index.css` `@theme`; mobile `global.css` text scale mirrors `src/lib/typography.ts`; `THEME_COLOR_ROLES` change -> web `APP_THEME_VARIABLES`, boot script, mobile generator (`pnpm generate`) and editor must all follow.
